# Özellik kartı görselleri

`card-1.jpg` … `card-5.jpg` — yatay kaydırma bölümündeki 5 özellik kartının
görsel/illüstrasyon alanı. Önerilen oran 4:3. Boş bırakılırsa kartlarda ikon +
nokta deseni gösterilir.

Şu an Unsplash'ten (ücretsiz lisans, images.unsplash.com) seçilmiş yer
tutucu fotoğraflar kullanılıyor — istersen kendi görsellerinle değiştir:

- `card-1.jpg` — Canlı Mahalle Akışı (komşuluk/topluluk teması)
- `card-2.jpg` — Ver-Al Pazar Yeri (ikinci el pazar/takas)
- `card-3.jpg` — Güvenilir Esnaf & Usta (alet/tamir teması)
- `card-4.jpg` — Sosyal Etkinlikler (parkta arkadaş buluşması)
- `card-5.jpg` — Güvenli Mesajlaşma (telefonda mesajlaşma)
